Setting a github repository for the first time.

when setting up a github repository for the first time you need the folowing steps

  • git init
  • git add .
  • git commit -m "message"
  • git branch -M main
  • git remote add origin https://github.com/Default-sudo/20th-october.git
  • git push -u origin main

Updating a github repository

When updating a github repository or pushing to an existing repository we use the following steps

  1. git add .
  2. git commit -m "message"
  3. git push
